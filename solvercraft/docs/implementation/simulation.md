# Simulation and distribution implementation evidence

Updated 2026-10-31. This is an implementation record, not a claim of complete legacy PSI compatibility. The full frozen PSI function inventory is maintained separately in `reference-catalog.json`; named aliases and specialist fit functions must be assessed individually.

## Public interfaces

`solvercraft_math` exposes validated `PreparedDistribution`, free `cdf`, `quantile`, and `sample`, `density::log_density`, `catalog::distribution_catalog`, `parameterization::from_two_quantiles`, `parameterization::lognormal_from_mean_std`, and `nominal::{nominal_value, nominal_summary}`. Distribution DTOs use explicit parameters: `Lognormal` stores underlying-normal log parameters. Arithmetic mean/std conversion is a separate checked constructor.

`solvercraft_simulation::simulate` preserves the established addressed v2 Monte Carlo and Latin Hypercube streams. New `advanced::{AdvancedSimulationOptions, simulate_advanced}` adds independently versioned randomized Sobol, copula dependence, invalid-trial policy, and bounded sequential mean stopping. Both runners return trial-major retained output rows only when requested. Callback allocation/work remains the host's responsibility.

`fitting::{fit_distribution, rank_fits}` returns fitted parameters, log likelihood, AIC, BIC, convergence/evaluation metadata, and optional refit-bootstrap GOF. `grid` and `intervals` provide separately tested parameter grids and fixed-sample/replicate-mean intervals.

## Resource and numerical boundaries

Distribution trees have at most16 levels/256 nodes; mixtures at most32 components; empirical inputs at most1million values; categorical inputs at most100000 values. Nondegenerate binomial trial count<=10000; Poisson rate<=512; logarithmic probability<=0.99 and inverse count<=100000; negative-binomial successes<=10000 and quantile<=1e9. Many special-function shape/df values are bounded to1e-4..1e4. Explicit discrete-uniform integer endpoints/count and returned geometric counts stay within exact binary64 integer precision.

Truncation requires resolvable retained CDF mass>=1e-9. Generic numerical mixture inversion and special-family quantiles have bounded bisection ranges/work and may reject extreme valid mathematical parameters with a structured numerical-range error. Positive interior underflow is not silently converted into a zero observation. New-family implementation limits are part of the catalog, not equivalent to the mathematical domains of vendor functions.

Simulation checks setup, retained rows, summaries, and scratch estimates before owned allocations. It caps10million attempts,4096 ordinary input/output dimensions,100million input/output sample slots. Advanced copulas have the narrower dimensions stated above. Parameter fitting prechecks worst-case observation/evaluation/bootstrap work and RAM. Native sorting, special-function preparation and a host callback remain bounded indivisible operations; no hard wall-clock cancellation latency is asserted.

Nominal spreadsheet declarations use finite implemented analytic means. If a mean is undefined or has no implemented analytic formula (for example generic truncation/Johnson-SB), `nominal_summary` labels the median fallback; numerical overflow still returns an error. Compound sums with unavailable severity means do not invent a nominal value.

## Mathematical sources and redistribution inventory

All production implementations are original Rust. No vendor binary, algorithm source, proprietary table, screenshot or copied package implementation is incorporated. Mathematical formulas are specifications, not imported code. Existing serde is the sole added serialization dependency; no RNG/numerics/native dependency was introduced for this area.

* NIST DLMF [Gamma](https://dlmf.nist.gov/5), [incomplete Gamma definitions](https://dlmf.nist.gov/8.2), [continued fractions](https://dlmf.nist.gov/8.9), [incomplete Beta](https://dlmf.nist.gov/8.17): mathematical definitions and series/continued-fraction identities. Lanczos coefficient numbers are mathematical constants used in an original bounded implementation; no third-party code or licensed data file is redistributed.
* Joe and Kuo, [Sobol notes](https://web.maths.unsw.edu.au/~fkuo/sobol/joe-kuo-notes.pdf): direction recurrence. Only the first63 polynomial/initial-direction rows (dimensions2..64) of [Boost.Random at22338471aa0f548bc92ddc351600ec4d510f164f](https://github.com/boostorg/random/blob/22338471aa0f548bc92ddc351600ec4d510f164f/include/boost/random/detail/sobol_table.hpp) are redistributed as numeric data in `crates/math/src/sobol_directions.rs`. Copyright Justinas Vygintas Daugmaudis2010–2018; Boost Software License1.0, full text retained in `crates/math/third_party/BOOST_LICENSE_1_0.txt`. No upstream algorithm code is copied. The upstream data are derived from Joe–Kuo2008. The earlier generated/all-one initial-direction development sampler is replaced with an explicitly new version; ordinary MC/LHS v2 streams are unchanged.
* Devroye and James, [On simulation and properties of the stable law](https://luc.devroye.org/devroye-james-stablesurvey-2013.pdf): positive-stable/Kanter representation used mathematically for multivariate Gumbel frailty. Original Rust implementation, no copied implementation.
* Hofert, [Sampling Archimedean copulas](https://hub.hku.hk/handle/10722/325169): frailty construction for Archimedean sampling. Public CDF formulas are separately differentiated and inverted in the bivariate implementation.
* NIST, [Kolmogorov–Smirnov goodness of fit](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35g.htm) and [dynamic GOF](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/goodfit.htm): fitted parameters require a suitable simulation calibration. [SciPy GOF documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.goodness_of_fit.html) independently describes refitting simulated samples; no SciPy code is used.
* The full official2025Q1 reference is frozen/read-only in the separately documented reference inventory. Public family names, signatures and documented semantics are used for clean-room mapping; no implementation is inferred from inaccessible vendor source.

## Remaining acceptance work

The remaining frozen PSI function inventory must be mapped against implementations and aliases, including exact import/worksheet wrappers and any unresolved vendor argument conventions. `elicitation` now provides a Myerson constructor with explicit bottom/median/top percentile semantics, the uniquely fitted generalized triangular distribution including0/1 endpoint claims, and the verified Vary actual-bounds distribution factory (Uniform/Triangular/PERT). Its three suites independently recover the requested percentiles and an asymmetric triangle. Myerson's documented argument-order erratum remains an import warning; Vary percentage/change modes and other family conventions are not inferred. The Vary factory returns a distribution; a host needing a distinct deterministic base-cell override must represent that separately from the distribution's canonical mean.

Metalog/OLS/SPT have a separately documented globally certified implementation in `metalog.md`, including an explicit distinction between quantile OLS and likelihood estimation. General Johnson moment inversion is documented in [johnson-moments.md](johnson-moments.md), with independent population-moment fixtures in `johnson_moments`; it must be assessed by achieved population moments rather than empirical fitting. Analytic anchors exist for many families; every unusual scalar parameter range and every formula-application wrapper still requires independent validation. Constrained precision/dimension/resource domains, missing weighted/censored fitting, and absent generic compound CDFs remain visible limitations. They must not be removed from acceptance merely to produce a100% figure.

Independent numerical review found and fixed finite log-density tail losses (Cauchy, skew normal and related log-domain formulas), discrete affine-reflection quantile boundaries, reflected copula conditional CDF semantics, beta-prime/F complementary-tail erasure, skew-normal quadrature cancellation, and a narrow large-scale reciprocal interval rounding bug. Information-criterion rankings now refuse mixed counting-measure PMFs and continuous PDFs without an explicit shared observation model. Sequential intervals are published only at configured checkpoints or the preselected final sample size; off-checkpoint, potentially data-adaptive cancellation does not receive a checkpoint-only confidence claim. Independent regression files remain under each crate's `tests/numerical_review.rs`.
