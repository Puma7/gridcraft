# Simulation capability and numerical contract

The package implements deterministic Monte Carlo and Latin Hypercube simulation. An evaluator receives one input vector per trial and returns a fixed, nonempty output vector. It is responsible for its own computation and allocations. Non-finite outputs, domain errors and changes in output count are errors; trials are not silently dropped.

Random samples are addressed by seed, input binding, trial and subcounter using the versioned solvercraft-addressed-mix64-v1 generator. This is for simulation, not cryptography. LHS uses independent Fisher-Yates permutations per dimension with open-interval jitter. The options and sampling version must both be retained for replay. No Sobol, copula or cross-input-correlation capability is claimed.

Constant, Uniform, Normal, Lognormal, Triangular, Bernoulli, Binomial, Poisson, Exponential, Weibull and equally-weighted empirical distributions are supported. Binomial has at most 10,000 Bernoulli trials per variate except degenerate p=0/1 cases; Poisson rate is at most 512. Larger unsupported parameter sizes return an explicit distribution_limit error. Distribution preparation validates domains and prepares discrete tables once. The normal inverse CDF uses Acklam's rational approximation; the normal CDF uses an erf approximation with absolute error around 1.5e-7, and is not an arbitrary-precision tail routine. Infinite endpoint quantiles return an error rather than a non-JSON number.

Streaming mode keeps Welford moments, extrema and counts, without a hidden full sample matrix. Exact empirical quantiles and tail risk are absent in this mode. With retain_samples=true, samples are row-major (outer index trial, inner index output) and summaries include lower-inverse empirical quantiles plus upper-loss-tail VaR95 and CVaR95. Expected shortfall integrates fractional probability mass at the VaR boundary. A loss sample [0,0,0,10] has CVaR at confidence 0.5 equal to 5. Sample variance uses n-1 and is absent for a single observation. Quantiles use the empirical inverse CDF, not interpolated order statistics.

All trial, dimension, preparation, LHS and retained-output sizes are checked before large allocations. There are at most 10,000,000 trials, 4096 inputs/outputs and 100,000,000 input draws. Input distributions and output vectors supplied by the caller already consume caller-managed storage. Cancellation is polled before preparation, during permutation creation and between trial evaluations. Host evaluator calls and standard-library sorting are indivisible; this package does not promise a wall-clock cancellation deadline. No IID confidence intervals are incorrectly attached to LHS.

Elementary fitting helpers expose normal mean/population-variance estimates, uniform endpoint estimates and an exponential MLE for nonnegative uncensored, unweighted observations. They do not claim distribution selection, goodness-of-fit, adjusted p-values or bootstrap validation.
