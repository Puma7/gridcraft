## Delivery scope

The independent SDK is Layer 4; Solvercraft CLI and the Gridcraft native/web
hosts are Layer 7. Existing Gridcraft MCP exposes the Solvercraft commands in
a headless workbook or running desktop session. The optional standalone local
job service uses authenticated JSON-lines TCP, not HTTP or standalone MCP.
Advanced mathematical workflows also remain available through CLI and SDK.

All 96 original acceptance rows retain their documented bounded acceptance.
The 31 selected PSI import forms do not establish all 272 reference functions
or full Frontline compatibility. No separate Solvercraft GUI, remote production
service, app-store registration or second ArtCraft product deployment is claimed.
See [remaining compatibility limits](reference-gaps.md).
